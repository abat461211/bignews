🔑 Підключення до GitHub

Адмінка зберігає статті прямо у твоєму репозиторії на GitHub. Для цього потрібен персональний токен. Створи його один раз (2 хвилини):
Як створити токен:

1. Відкрий github.com/settings/tokens/new (ти вже залогінений)
2. У полі Note напиши: bignews admin
3. Expiration — обери термін (наприклад, 90 днів або No expiration)
4. Познач галочку repo (повний доступ до репозиторіїв)
5. Натисни Generate token внизу сторінки
6. Скопіюй токен (він показується тільки один раз!) і встав його нижче
